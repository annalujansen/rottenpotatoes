# RottenPotatoes

Aplicação RottenPotatoes desenvolvida em Ruby on Rails.

## Como executar o projeto

### Instalar as dependências

Na pasta do projeto, execute:

```bash
bundle install
```

### Preparar o banco de dados

Execute:

```bash
bin/rails db:prepare
bin/rails db:seed
```

### Executar os testes

Execute:

```bash
bin/rails test
```

### Iniciar o servidor

Execute:

```bash
bin/rails server
```

Depois, acesse no navegador:

http://localhost:3000/movies
